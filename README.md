## 📌 Sobre o Projeto

O **Meu Portal de Entretenimento Digital** é uma página web temática desenvolvida com **HTML5** e **CSS3**, utilizando a identidade visual **Roxo Retrô / Vintage Violet**.

O projeto tem como objetivo aplicar conceitos fundamentais de desenvolvimento web, incluindo:

- Estruturação semântica em HTML5;
- Estilização com CSS nos três níveis: inline, interno e externo;
- Layout responsivo com **Flexbox**;
- Uso de seletores, classes e IDs;
- Boas práticas de organização e documentação de código.

O Flexbox foi utilizado para organizar as seções em colunas, permitindo que os elementos se ajustem de acordo com o espaço disponível na tela. [6]

---

## 📚 Seções Temáticas

### 1. Filmes & Séries — *House, M.D.*

Análise da construção do anti-herói na televisão dos anos 2000, explorando o cinismo, o racionalismo e os dilemas éticos presentes no drama médico.

### 2. Música & Podcasts — *Chico Buarque*

Estudo lírico e métrico da MPB na década de 1970, destacando obras como *Construção* e *Cálice*, com uma análise sobre o formato de podcast.

### 3. Games & Tecnologia — *The Last of Us*

Investigação sobre a narrativa transmídia e o *game design* interativo, abordando a adaptação da obra dos videogames para a série de televisão.

## 🛠️ Requisitos Técnicos

- [x] **CSS inline:** aplicado diretamente no elemento `<footer>`;
- [x] **CSS interno:** inserido dentro da tag `<style>`, no `<head>` do documento;
- [x] **CSS externo:** vinculado por meio do arquivo `estilo.css`;
- [x] **CSS Reset:** utilização do *Reset CSS* de Eric Meyer, carregado antes do estilo principal, para reduzir inconsistências visuais entre navegadores; [13]
- [x] **Layout Flexbox:** organização das três seções lado a lado, em colunas ajustáveis e responsivas, com `display: flex`; [4]
- [x] **Seletores de classes e IDs:** aplicados para padronizar títulos, imagens e cartões com bordas temáticas;
- [x] **Comentários no CSS:** código documentado com explicações das principais propriedades utilizadas;
- [x] **Mentoria com IA:** registro documentado das interações com Inteligência Artificial durante o desenvolvimento.
